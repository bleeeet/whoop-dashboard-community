这是初始化页面的静态预览

真实部署后第一页就是这个样子：上面的回调地址会自动换成你自己的域名，复制按钮也能用。本文件只供查看，不能在这里完成初始化——请按 README 部署后在线填写。

新手引导：约 5 分钟完成初始化

第一次使用，跟着下面 7 步走一遍就好，大约 5 分钟。你要拿到的只有 Client ID 和 Client Secret 两个值——WHOOP 没有“一个 API Key”，而是“两个值 + 一次登录授权”，授权一次后网站会自动续期，以后不用再填。

DeepSeek 可以跳过：不填也能自动抓数据、看全部图表和周报，之后随时能在设置里补。

整体流程：
① 复制回调地址 → ② 在 WHOOP 开发者后台创建 App、填回调地址、勾 6 个权限 → ③ 复制 Client ID / Secret 填回下面表单 → ④ 保存后点「连接 WHOOP」登录并同意授权 → 完成。

1复制这两个地址，后面两处要用

回调地址（要填进 REDIRECT URLS）：

https://whoop.example.com/oauth/callback

隐私政策地址（要填进 PRIVACY POLICY，网站自带这个页面）：

https://whoop.example.com/privacy

2登录 WHOOP 开发者后台

用你的 WHOOP 账号（手环 App 那个）登录。第一次进入如果提示创建 Team，随便起个名字创建即可；已有 Team 会直接进入团队页。

打开 WHOOP 开发者后台 →

3新建一个 App

点顶部 APPS，在「Your apps」页面右上角点 CREATE NEW APP。

4填名字和联系邮箱

NAME：随便填，例如「我的健康工作台」（授权时会显示这个名字）
LOGO：可以不传
CONTACTS：填你自己的邮箱

5填隐私政策和回调地址（最容易错的一步）

PRIVACY POLICY（必填，不填无法创建）：粘贴第 1 步那个以 /privacy 结尾的地址
REDIRECT URLS → Redirect #1：粘贴第 1 步那个以 /oauth/callback 结尾的地址

必须和这里显示的一字不差：以 https:// 开头、以 /oauth/callback 结尾、末尾没有多余的 / 、没有空格。填错会导致最后一步授权失败。

6勾选 6 个权限，然后创建

在 SCOPES 里把 6 项全部勾上：

read:recoveryread:cyclesread:sleepread:workoutread:profileread:body_measurement

WEBHOOKS 不用填。最后点 CREATE APP。

7复制 Client ID 和 Client Secret

创建后进入 App 详情页，Credentials 区域就是你要的两个值：Client ID 直接复制；Client Secret 默认显示为星号，点右边的眼睛图标显示后再复制。

Client Secret 相当于密码：只填进你自己的网站，不要发到聊天、群里或发给别人。页面上的“SANDBOX · 10 MEMBERS”是正常状态，个人使用不用升级。

第 8 步：填写并保存

常见问题

点「连接 WHOOP」后报错 / 授权失败？

99% 是回调地址不一致。复制这个地址：

https://whoop.example.com/oauth/callback
到 WHOOP App 的编辑页逐字核对。

创建 App 时提示 Privacy Policy URL is required

第 5 步的 PRIVACY POLICY 没填，填 https://whoop.example.com/privacy。

首页显示「同步失败」或数据没更新

先打开 WHOOP 手机 App 让手环同步，再在网站首页点「立即同步」。

以前建过 App（比如本地版用的 localhost 回调）

不用重建：在 App 详情页点右上角铅笔图标进入编辑，把 Redirect 改成这个网站的地址（或用 ADD 新增），Privacy Policy 也可改成网站的 /privacy，保存即可。Client ID / Secret 不变。

DeepSeek API Key 怎么获取（选填）

打开 platform.deepseek.com，注册登录后充值少量余额（几元即可，每次分析约几分钱）→ 左侧菜单 API keys → 创建，复制以 sk- 开头的密钥（只显示一次）→ 粘贴到设置页。模型保持默认即可。

AI 分析只发送最近 30 条记录的汇总统计（平均值、最大最小值），不发送姓名、邮箱或原始记录。
