WHOOP 通用版 · Workbuddy 一键部署

1. 把整个压缩包直接发给 Workbuddy，不用自己解压。
2. 告诉它：“一键部署”。
3. 打开它提供的网站链接。
4. 后续配置按照包内《WHOOP API 获取教程.pdf》的方法操作即可。
   创建自己的 WHOOP 应用，把 Client ID 和 Client Secret 填入自己的网站，设置登录密码，再点击“连接 WHOOP”授权。
5. DeepSeek 选填；不填也能抓取数据、看图表和周报。
6. 手机打开网站，可添加到主屏幕。

密钥只填入自己的网站，不要发给 Workbuddy 或公开分享。
部署细节见 WORKBUDDY.md；每周自动周报见 WEEKLY_AUTOMATION.md。
